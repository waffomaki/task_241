# ФС

1) Какие файловые системы вы знаете?<br>
Linux: XFS, Ext4, Btrfs, ZFS<br>
Windows: NTFS, FAT<br>
macOS: HFS<br>

2) Как можно классифиировать файловые системы? в чём отличия??
Журналируемые и не журналируемые.<br>
Журналируемые хранят информацию о действиях пользователей и позволяют посмотреть, выполнить диагностику системы в отдельном специальном файле. Отличаются повышенной стойкостью к сбоям в функционировании, сохранностью целостности данных.<br>
Не журналируемые не хранят логи и не гарантируют сохранность информации.<br>

3) Какие файловые системы используются в linux?<br>
Журналируемые: Ext4, XFS, Btrfs, JFS<br>
Не журналируемые: Ext2, tmpfs<br>

4) Как можно создать файловую систему на диске?<br>
Используется команда mkfs(make filesystem): ```sudo mkfs -t <тип_фс> <устройство>```, где ```-t``` указывает на тип фс.<br>
Перед этим диск разбивают на разделы, например, с помощью fdisk.<br>

5) Как можно подключить диск в систему, что такое монтирование?<br>
Монитирование - присоединение раздела диска к катологу Linux.<br>
Подключение диска к новому каталогу: ```sudo mount [опции] <устройство> <точка_монтирования>```<br>

6) файловая система procfs, cifs, tpmfs,sysfs. В чём особенности каждой из них?<br>
**procfs** предоставляет userspace мгновенный снимок состояния ядра и процессов, которыми оно управляет. В /proc ядро выдаёт информацию о доступных ему ресурсах, таких как прерывания, виртуальная память и планировщик.<br>
**Tmpfs** предназначена для размещения пользовательских файлов непосредственно в оперативной памяти компьютера. Подразумевает создание блочного устройства заданного размера с последующим монтированием в каталог. При необходимости данные могут быть удалены.<br>
Файловая система **sysfs** — это псевдофайловая система, предоставляющая интерфейс к структурам данных ядра: файлы и каталоги в sysfs отображают kobject, определённые внутри ядра. Файлы в sysfs содержат информацию об устройствах, модулях ядра, файловых системах и других компонентах ядра. Обычно sysfs монтируется в `/sys` автоматически системой.<br>
**CIFS (Common Internet File System)** — это сетевая файловая система, позволяющая монтировать удалённые общие ресурсы (шары), предоставляемые серверами, совместимыми с протоколом SMB, например, Windows-серверами или Samba.<br>
Файлы и каталоги на удалённом ресурсе становятся доступны локально как обычная файловая система.<br>
Обычно CIFS монтируется вручную в произвольный каталог с помощью команды `mount -t cifs`, с указанием сетевого пути, учётных данных и других параметров подключения.<br>

Вывести каталоги к которым примонтированы эти файловые системыю<br>
Можно использовать для этого ```findmnt -t proc,sysfs,tmpfs,cifs```<br>

7) Как можно получить информацию о системе используя лишь команду cat?
вывести ифонмацию о процессоре и состоянии памяти системы<br>
Нужно читать файлы из вирутальной файловой системы ```/proc```:<br>
```cat /proc/cpuinfo``` - о процессоре<br>
```cat /proc/meminfo``` - о памяти<br>
