# Струтура каталогов

1) Какая структура каталогов в linux? выведите список файлов в корне системы<br>
Стандарт FHS (Filesystem Hierarchy Standard). Иерархическая структура, начинающаяся с ```/```.<br>

2) Где хранятся папки пользователей в системе?<br>
Папки каждого пользователя (кроме рута) имеет подпапку в каталоге /home/<br>

3) Где домашняя папка суперпользователя?<br>
В каталоге /root<br>

4) Где хранятся основые конфигурационные файлы в системе?<br>
Раздел /etc/ является основным для конфигурационных файлов.<br>

5) ЧТо за папки /bin,/sbin,usr/sbin,/usr/sbin<br>
В /bin находится бинарные файлы, которые необходимы для операционной системы. Здесь все основые команды ядра Linux.<br>
В /sbin находятся системные исполняемые файлы. Эти программы можно выполнить только с правами суперпользователя.<br>
В /usr/bin находятся исполняемые файлы программ, которые не требуются на первых этапах загрузки.<br>
в /user/sbin находятся бинарные файлы для системного администрирования, например, useradd.
