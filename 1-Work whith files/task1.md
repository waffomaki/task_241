# Работа в консольке

1) Переместиться между директориями<br>
```cd <путь>``` - переход по директории<br>
```cd ..``` - подняться на уровень<br>
```cd ~``` - возврат в доманюю директорию<br>
2) Вывести список файлов в директории<br>
```ls```<br>
3) Вывести список Всех файлов в директории<br>
```ls -a``` - для вывода скрытых файлов<br>
4) Создать папку с подпапками<br>
```mkdir fol1``` - создание директории<br>
```mkdir -p fol/sfol/``` - создание дерева директорий<br>
5) Внутри папки создать файлик и записать в него что-нибудь<br>
```cd fol1```<br>
```touch file.txt``` - создание текстового файла file.txt<br>
```echo (текст) > file.txt``` - записывает строку + '\n' в конце, содержимое перезаписывается. Без перевода используется флаг '-n'.<br>
Вводим: ```echo HelloWorld! > file.txt```<br>
6) Переместить файл из одно директории в другую<br>
Создадим еще одну папку в fol1: ```mkdir fol2```<br>
Переместим: ```mv file.txt fol2```<br>
7) скопировать файл из одной директории в другую<br>
![t1_1.png](src/t1_1.png)<br>
```cp ~/fol/fol1/fol2/file.txt ~/fol/fol1``` - копирование файла<br>
![t1_2.png](src/t1_2.png)<br>
8) переименовать файл<br>
```mv file.txt file1.txt```<br>
9) сравнить содержимое файла<br>
Команда ```diff <file1> <file2>``` сравнивает файлы построчно.<br>
Значит, ```diff file1.txt fol2/file.txt```.<br>
Можно добавить флаг ```-s```, чтобы было видно наглядно:<br>
![t1_3.png](src/t1_3.png)<br>
10) отсортировать содержимоей файла по возрастанию и убыванию<br>
```cat file1.txt``` - вывод содержимого текстового файла:<br>
![t1_4.png](src/t1_4.png)<br>
Строка одна, поэтому дополним файл:<br>
```echo 1Hello >> file1.txt```<br>
```echo 2Hello >> file1.txt```<br>
```echo 3Hell >> file1.txt```<br>
Используем ```>>``` для перенаправления с добавлением.<br>
Результат:<br>
![t1_5.png](src/t1_5.png)<br>
Сортируем: ```sort file1.txt > sort_file1.txt``` (флаг ```-r``` по убыванию, ```-n``` для чисел, ```-f``` для игнорирования регистров)<br>
Результат:<br>
![t1_6.png](src/t1_6.png)<br>
11) удалить все папки и файлы<br>
Используем ```rm -rf``` для рекурсивного удаления:<br>
