# Перенаправляем

1) Как работают команды >,>>?<br>
Это операторы перенаправления вывода.<br>
```>``` используется при перезаписи файла, тогда как ```>>``` добавляет в конец.<br>
В предыдущем задании в моем решении оба использовались.<br>
2) Что такое перенаправление ввода? stderr,stdout;<br>
```<``` - перенаправление stdin (стандартный ввод) из файла. Файловый дескриптор 0.<br>
```>```, ```>>``` - перенаправление stdout (стандартный вывод) в файл (перезапись, добавление соответственно). Файловый дескриптор 1.<br>
```2>```- перенаправление stderr (стандартный вывод ошибок) - аналогично предыдущему, записывает ошибки. Файловый дескриптор 2. <br>
3) Выести содержание файла не используя текстовые редакторы;
```cat <файл>```
4) Создать файл с содержимым не используя текстовые редактор;
```touch file.txt``` - создание текстового файла file.txt<br>
```echo (текст) > file.txt``` - записывает строку + '\n' в конце, содержимое перезаписывается. Без перевода используется флаг '-n'.<br>
```printf "Строка 1\nСтрока 2\n" > file.txt``` - позволяет гибко форматировать строку.<br>
Записывание множества строк через cat:<br>
```
cat > file.txt <<EOF
строка1
строка2
EOF
```

5) пернеаправить stdout в stderr и обратно на примере команды kinit, ping, tracert<br>
На примере ping (stdout → stderr): <br>
```ping 2 test.com 1>&2```<br>
kinit (stderr → stdout):<br>
```kinit test@REALM 2>&1```<br>
tracert (tracepath в alt, stdout в stderr и наоборот):<br>
```tracepath ya.ru > trace.log 2>&1```<br>
6) чем отличаются stdout и stderr<br>
stdout используется для обычного вывода программы, а stderr для сообщения об ошибках<br>
7) что такое stdin?<br>
stdin (standart input) - это стандартный поток ввода. Отсюда читаются входные данные по умолчанию. Писал выше.<br>
8) как отправить весь вывод команды в пустоту?<br>
Используется ```/dev/null``` (черная дыра). Все, что туда попадает, исчезает.<br>
Пример (пинг в пустоту): ```ping example.com > /dev/null```
